
# Python Assignment 02

This project contains the solutions for **OOP Bank Account System and pandas Dataset Analysis**.

## Files

* `question.md` - Assignment questions
* `bank_account.py` - Bank account classes
* `main_bank.py` - Banking system demonstration
* `dataset_analysis.py` - Dataset analysis using pandas and NumPy
* `titanic.csv` - Dataset used for analysis

## Dataset

Titanic Dataset: https://github.com/datasciencedojo/datasets/blob/master/titanic.csv

## Requirements

* Python 3
* pandas
* NumPy

## Run

```bash
python main_bank.py
```

```bash
python dataset_analysis.py
```
